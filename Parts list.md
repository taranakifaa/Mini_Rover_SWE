# Raspberry Pi Robot - Parts List

Reference: Adafruit Simple Raspberry Pi Robot  
Hardware Guide: https://learn.adafruit.com/simple-raspberry-pi-robot/hardware

## Main Components

| Qty | Component | Description |
|---:|---|---|
| 1 | Mini Rover Robot Chassis Kit | Robot chassis with two DC motors, two wheels, front caster wheel, top plate, and mounting hardware |
| 1 | Raspberry Pi | Raspberry Pi Model 2 or newer; newer Raspberry Pi models can also be used |
| 1 | Adafruit DC & Stepper Motor HAT | Motor driver board used to control the two DC motors from the Raspberry Pi |
| 2 | M2.5 Brass Standoffs | Used to securely mount the Motor HAT to the Raspberry Pi |
| 1 | 4x AA Battery Holder with Switch | Separate power source for the DC motors |
| 4 | AA Batteries | Powers the motors through the battery holder |
| 1 | USB Battery Pack | Portable 5V power source for the Raspberry Pi |
| 1 | Wi-Fi Adapter | Optional for Raspberry Pi models without built-in Wi-Fi |
| 2 | #4-40 Machine Screws | 3/8" or longer; used to mount the Raspberry Pi to the chassis |
| 2 | #4-40 Nuts | Used with the Raspberry Pi mounting screws |
| 1 | Small Piece of Cardboard | Electrical insulation between the Raspberry Pi PCB and metal chassis |
| As Needed | Jumper Wires | Electrical connections between components |

## Included With Rover Chassis Kit

- 1x Aluminum Robot Chassis
- 2x DC Motors
- 2x Motor Wheels
- 1x Front Caster Wheel
- 1x Top Plate
- Chassis standoffs / mounting hardware

## Tools Required

- Precision Screwdriver Set
- Small Adjustable Wrench or Pliers
- Soldering Iron
- Solder
- Wire Cutters / Strippers

## Power Configuration

### Raspberry Pi Power
USB Battery Pack
→ Raspberry Pi

### Motor Power
4x AA Battery Pack
→ Motor HAT
→ Left and Right DC Motors

> **Important:** The motors should use their own battery supply. Do not attempt to power the motors directly from the Raspberry Pi.

## Optional / Recommended

- MicroSD Card for Raspberry Pi OS
- MicroSD Card Reader
- USB Cable for Raspberry Pi battery pack
- Additional jumper wires
- Zip ties / cable management
- Double-sided mounting tape
